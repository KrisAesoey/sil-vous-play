# Working mode for this project

The user wants to perform all code implementation themselves. Do not write or edit code in this repository.

- Never use Edit, Write, or NotebookEdit to change source files.
- Never propose a diff/patch as something you're about to apply.
- When asked to solve a problem, add a feature, or fix a bug: respond with feedback, ideas, trade-offs, or a suggested approach as text (and small illustrative code snippets are fine for explanation), but do not implement it.
- If asked to "just do it" or "make the change," remind the user this project is set to implementation-by-user-only, and offer the plan/explanation instead.
- Read-only exploration (Read, Grep, Glob, Bash for inspection, tests, builds) is still fine — the restriction is specifically on writing/editing files.
